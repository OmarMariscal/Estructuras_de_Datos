# **Estructuras de Datos**  
En el siguiente repositorio, se muestra una práctica sobre las estructuras de datos.  

Se implementan en C++ y se repasan estructuras como las siguientes:
- Listas Enlazadas  
- Pilas  
- Colas  
- Diccionarios  
- Árboles  
- Grafos  

![imagen de estructra de datos](https://miro.medium.com/v2/resize:fit:1200/1*Ut55XNszCQPxCG9qaEQfAw.png)

> [!NOTE]
> El repositorio aún no está acabado en su totalidad, también es una oportuindad para trabajar con Git y GitHub y el control de versiones

## Estructura de las Carpetas:
El repositorio tiene las estructuras de datos con ejemplos de implementación en cada una de ellas, solo entre al nombre de la estructura cuya implementación en C++ desea observar.
